# Gallery Implementation (as of July 27, 2025)

## Overview
This describes the current 3D vertical image gallery (carousel) implementation on the Build Service page, including all relevant React, CSS, and theme logic. This is intended for future reference so the gallery can be restored exactly as it is now.

---

## 1. Gallery Container Structure
- The gallery is rendered in the left column of the Build Service page grid.
- The outermost container is a flexbox centering a `relative` div.
- There is a background shape (rounded rectangle, absolute, 280x760px, no background color by default).
- The main gallery container is a `div` with:
  - `relative z-40 flex items-center justify-center bg-white dark:bg-black`
  - Inline styles:
    - `width: 240px; height: 680px; overflow: hidden; borderRadius: 12px;`
    - `maskImage` and `WebkitMaskImage` set to a vertical linear gradient for fade (transparent at top/bottom, white in the middle).

---

## 2. Carousel Component (`HorizontalCarousel`)
- Renders a `<ul>` absolutely positioned, with:
  - `width: 240px; height: 680px; transform: translateX(-50%); transformStyle: preserve-3d;`
- Each image is a `<li>` with:
  - `absolute left-1/2 top-1/2 bg-white dark:bg-black`
  - Inline styles:
    - `width: 155px; height: 155px; borderRadius: 12px; overflow: hidden; filter: brightness(0.95) saturate(0.9);`
    - 3D transform: `translate(-50%, -50%) rotateX(angle) translateZ(radius)`
    - Only images in the front 180° arc are visible (opacity: 1, pointerEvents: auto); others are hidden (opacity: 0, pointerEvents: none).
- The images are sourced from the `articles` array (first 10 images).
- The carousel rotates smoothly using a `requestAnimationFrame` loop, incrementing the angle.
- The shine overlay (`#carousel-light-overlay`) is a radial gradient, animated to rotate with the carousel.

---

## 3. Overlays & Effects
- **Vertical shadow overlay:**
  - Absolutely positioned, pointer-events-none, full size of the gallery container.
  - Inline style: `background: linear-gradient(to bottom, rgba(0,0,0,0.65) 0%, transparent 20%, transparent 80%, rgba(0,0,0,0.65) 100%)`, `borderRadius: 12px`.
  - This overlay is always black, regardless of theme (should be made theme-aware for perfect light mode support).
- **Shine overlay:**
  - Absolutely positioned, pointer-events-none, 220x220px, radial gradient, mix-blend-mode: screen, animated rotation.

---

## 4. Theme Support
- The gallery container and carousel items use `bg-white dark:bg-black` for theme-aware backgrounds.
- The shadow overlay is currently always black (not theme-aware).

---

## 5. Masking
- The gallery container uses both `maskImage` and `WebkitMaskImage` for vertical fade.
- The mask is a linear gradient: `linear-gradient(to bottom, transparent 0%, white 14%, white 86%, transparent 100%)`.
- This works in Chrome, but may have issues in Safari due to browser differences in mask support.

---

## 6. Known Issues
- Shadow overlay is not theme-aware (should be white in light mode, black in dark mode).
- Safari may render the 3D carousel or mask differently than Chrome.
- The background shape behind the gallery is transparent unless a background class is added.

---

```
      style={{
        width: 240,

    </div>
  </div>
</div>
```
